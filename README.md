# My Awesome Resume

Welcome to my resume repository! Tired of paying for online resume services? Me too! That's why I've taken matters into my own hands. With this repository, I've templated my own resume using HTML and CSS, giving me total control over what's on it and how it's laid out. No more restrictions!

## Why DIY?

- **Freedom:** Customize everything from layout to content. It's your resume, your rules.
- **Convenience:** Simply open the HTML file in any browser and print to PDF. Voila, you're done!
- **Cost-effective:** No more subscription fees or hidden charges. Just pure, unadulterated resume freedom.

## Features

- **Easy Printing:** Just open in a browser and print to PDF for a polished look.
- **Customizable:** Tweak the HTML and CSS to match your style and personality.
- **Accessible:** Keep your resume up-to-date without relying on third-party services.

## Getting Started

1. Clone this repository.
2. Open `Hayden_Westfall.html` in your favorite browser. (Probably want to rename it)
3. Customize the content and style to your heart's content.
4. Print to PDF and showcase your awesome skills!
